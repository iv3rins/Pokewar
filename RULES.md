# PokeWar Rules

The normative game rules live in [`references/RULES.md`](references/RULES.md).

- Treat `references/RULES.md` as read-only during feature implementation.
- Rule changes require explicit product approval, an ADR when behavior or protocol compatibility changes, and updated domain tests.
- Unresolved behavior is tracked in [`docs/OPEN_QUESTIONS.md`](docs/OPEN_QUESTIONS.md). Do not invent answers in code.
